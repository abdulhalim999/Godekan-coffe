# Годекан — сайт кофейни-кафе

Одностраничный сайт кофейни в горском (кавказском) стиле: светлая и тёмная тема,
адаптация под телефоны и планшеты, демо-ассортимент и оформление заказа с корзиной.

**Сайт вживую:** <https://abdulhalim999.github.io/Godekan-coffe/>

## Запуск

```bash
node server.mjs
```

Затем откройте <http://localhost:5173>. Сборка не нужна — это чистые ES-модули и CSS.
Любой статический сервер тоже подойдёт (`npx serve`, nginx, GitHub Pages).

> Открывать `index.html` двойным кликом нельзя: браузер блокирует ES-модули
> по протоколу `file://`. Нужен http-сервер — для этого и лежит `server.mjs`.

## Архитектура

Зависимостей нет — ни рантайма, ни сборщика. Это осознанный выбор: сайт-витрина
живёт годами, а любая сборка требует обновлений. Модульность при этом сохранена.

```
index.html                 разметка + спрайт иконок + анти-мигание темы
server.mjs                 статический dev-сервер (без зависимостей)
src/
  main.js                  точка входа: собирает модули и связывает их
  core/                    инфраструктура, ничего не знает о кофейне
    dom.js                 el/qs/render/delegate, блокировка прокрутки
    store.js               реактивный стор с подпиской и localStorage
    format.js              цены, склонения, маска телефона
    overlay.js             ловушка фокуса, Escape, возврат фокуса
  data/
    menu.js                ассортимент + fetchMenu() — точка подключения API
  features/                предметные модули, каждый самодостаточен
    theme.js               светлая / тёмная / системная
    nav.js                 мобильное меню, подсветка раздела
    menu-view.js           фильтры, поиск, карточки
    cart.js                состояние корзины (без DOM)
    cart-view.js           панель корзины и счётчики
    order.js               модалка заказа, валидация, подтверждение
    toast.js               уведомления
    reveal.js              появление блоков при прокрутке
  styles/
    main.css               порядок каскадных слоёв и импорты
    base/                  сброс, токены, типографика, сетки, утилиты
    components/            по файлу на компонент
```

Принципы, которые держат код в порядке:

- **Данные отдельно от вида.** `cart.js` — только состояние и селекторы,
  `cart-view.js` — только DOM. Логику корзины можно покрыть тестами без браузера.
- **Каскадные слои.** `@layer reset, tokens, base, layout, components, utilities`
  задают приоритет один раз; специфичность селекторов больше ни на что не влияет.
  В коде нет ни одного `!important`, кроме служебного `[hidden]`.
- **Токены вместо цветов.** Компоненты используют роли (`--surface`, `--accent`),
  а не конкретные значения. Тема меняется в одном файле.
- **Одна точка подключения бэкенда.** `fetchMenu()` в `data/menu.js` и
  `submitOrder()` в `features/order.js` — заменяются на `fetch`, UI не трогается.

## Темы

Три режима по кругу: **День → Ночь → Авто** (следует системной настройке).
Выбор хранится в `localStorage`, а инлайн-скрипт в `<head>` применяет тему
до первой отрисовки — вспышки белым не бывает. Заодно обновляется
`<meta name="theme-color">`, чтобы совпадала строка состояния в мобильном браузере.

Контраст текста к фону проверен: во всех парах ролей ≥ 4.5:1 (WCAG AA).

## Адаптивность

| Ширина | Раскладка |
| --- | --- |
| < 768 px | одна колонка, бургер-меню, корзина листом снизу, плавающая панель заказа |
| 768–959 px | две колонки, бургер-меню, кнопка «Заказать» в шапке, корзина панелью справа |
| ≥ 960 px | полная навигация, 3–4 колонки в сетках, мозаика галереи 4 × 2 |

Сетки собраны на `auto-fit` + `minmax`, размеры — на `clamp()`, поэтому
промежуточные ширины не ломаются. Учтены `safe-area-inset` (вырез iPhone),
`prefers-reduced-motion` и полноэкранные единицы `svh`.

## Заказ

1. «В заказ» на карточке — товар уходит в корзину, кнопка превращается в счётчик.
2. Корзина живёт в `localStorage`: перезагрузка страницы её не теряет.
3. «Оформить заказ» открывает модалку: способ получения (в зале / самовывоз /
   доставка), имя, телефон с маской, время, комментарий.
4. Валидация на месте, доставка считается автоматически: 200 ₽, бесплатно от 1500 ₽.
5. После отправки — номер заказа вида `ГД-4821` и очистка корзины.

Отправка имитируется в `submitOrder()` — заказ выводится в консоль. Ассортимент,
цены, адрес и телефон демонстрационные.

## Доступность

- Навигация с клавиатуры по всему сайту, видимый фокус, ссылка «К содержанию».
- В корзине и модалке — ловушка фокуса, закрытие по `Escape` и клику по подложке,
  возврат фокуса на кнопку, которая их открыла.
- Живые области `aria-live` для уведомлений, осмысленные `aria-label` у кнопок
  со счётчиками, стрелки ← → для переключения фильтров меню.

## Публикация

Сайт выложен на GitHub Pages: источник — ветка `main`, корень репозитория.
Сборки нет, поэтому публикация сводится к слиянию в `main` и пушу:

```bash
git switch main
git merge develop
git push
```

Через минуту-две изменения оказываются на <https://abdulhalim999.github.io/Godekan-coffe/>.
В корне лежит пустой файл `.nojekyll` — он отключает шаблонизатор Jekyll,
который сайту не нужен.
